# PA Assistant — ระบบช่วยกรอกแบบประเมินผลการปฏิบัติงาน

**คณะศิลปศาสตร์ มหาวิทยาลัยมหิดล** | ระบบ AI ช่วยกรอก PA Form

---

## ฟีเจอร์หลัก

| ฟีเจอร์ | รายละเอียด |
|---|---|
| 📋 แบบฟอร์ม PA ครบทุกเกณฑ์ | หมวด 1–5 ครบ 70+ รายการ พร้อมเกณฑ์คะแนน |
| 📂 Drag-and-Drop | ลากไฟล์หลักฐาน PDF/Word/รูปวางได้เลย |
| 🤖 AI Auto-match | จับคู่ไฟล์กับเกณฑ์อัตโนมัติจากชื่อไฟล์ (2_1_1_IRB → 2.1.1) |
| ⚡ AI สกัดข้อมูล | Claude AI อ่านเอกสารแล้วกรอกคำอธิบาย + แนะนำคะแนน |
| ✏️ แก้ไขได้ทุกช่อง | ตรวจสอบและปรับแก้ AI ได้ทันที |
| 📥 Export Word | ดาวน์โหลด .doc ที่มีโครงสร้างเหมือน MASTER_PA |

## การติดตั้ง (Development)

```bash
# ติดตั้ง dependencies
npm install

# รันในเครื่อง
npm run dev

# เปิด browser ที่ http://localhost:5173
```

## Deploy ขึ้น Vercel (แนะนำ)

1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub
2. ไปที่ [vercel.com](https://vercel.com) → New Project → Import GitHub repo
3. Framework: **Vite** | Build: `npm run build` | Output: `dist`
4. Deploy → ได้ URL สาธารณะทันที

## Deploy ขึ้น Netlify

1. รัน `npm run build` ในเครื่อง
2. ลากโฟลเดอร์ `dist/` ไปวางที่ [netlify.com/drop](https://app.netlify.com/drop)

## วิธีใช้งาน

```
1. เปิดแอป → กรอก/ตรวจสอบข้อมูลส่วนตัว (คลิก "ข้อมูลส่วนตัว")
2. ลากไฟล์หลักฐานมาวางในแผงซ้าย
   → ระบบจะจับคู่อัตโนมัติจากชื่อไฟล์ เช่น "3_4_จดหมาย..." → เกณฑ์ 3.4
3. ตรวจสอบ/แก้ไขการจับคู่ (คลิก badge สีเขียวที่ไฟล์)
4. คลิก "⚡ AI สกัดทั้งหมด" หรือ "⚡ AI" รายการ → AI กรอกให้
5. ตรวจสอบข้อมูล แก้ไขตามต้องการ
6. กรอกคะแนนประเมินตนเอง (0–10)
7. คลิก "📥 Export Word" → ดาวน์โหลด .doc
```

## ข้อควรระวัง

- คะแนนที่ AI แนะนำเป็นเพียงข้อเสนอแนะ — **ต้องตรวจสอบและตัดสินเองก่อน Submit**
- ข้อมูลทั้งหมดอยู่ในเบราว์เซอร์เท่านั้น ไม่มีการส่งข้อมูลส่วนตัวออกนอกจาก API call ไป Claude
- สำหรับไฟล์ที่เป็นภาพสแกน (image-only PDF) AI อาจสกัดข้อมูลได้น้อยกว่าไฟล์ที่มีข้อความ
